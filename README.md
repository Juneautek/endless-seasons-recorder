# Endless Seasons Studio (recorder)

A single-page, offline-capable voice recorder and interview-prompt app for a memoir project.

- Records audio and live-transcribes in the browser (when the browser supports it).
- Works with no signal after the first visit. Add it to your Home Screen to install.
- Everything you record stays in your own browser storage on your own device. Nothing is uploaded.
- No accounts, no analytics, no external requests.
